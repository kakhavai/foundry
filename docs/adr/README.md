# Architecture Decision Records

ADRs capture significant, hard-to-reverse decisions — the *why* behind a choice, the
options weighed, and the consequences accepted. They are immutable once accepted; a later
decision that changes course gets a new ADR that supersedes the old one.

Format: lightweight MADR. Filename: `NNNN-kebab-title.md`, numbered sequentially.
